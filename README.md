# Arpitha & Yeshwanth - Wedding Invitation

An animated e-invitation. It is a single self-contained page (`index.html`): fonts and illustrations are built in, nothing else to install.

- Reception: 21 November 2026, 7:00 pm onwards
- Muhurtha: 22 November 2026, 10:30 am to 11:15 am
- Venue: Poornima Convention Hall, Jayanagar, Bengaluru

## Put it online with GitHub Pages
1. Create a new repository and upload `index.html` and `.nojekyll` (the `images` folder is optional).
2. Open **Settings > Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
3. After a minute the link appears there, usually `https://<your-username>.github.io/<repo-name>/`. Share that link.

The `images` folder has still pictures of each panel for sharing on WhatsApp.
